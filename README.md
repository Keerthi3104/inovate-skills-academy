# Inovate Solution Technology — Skills Academy (Enhanced UI/UX Prototype)

A premium, bespoke, fully responsive frontend website prototype designed and developed for the **Skills Academy** division of **Inovate Solution Technology (IST)**, Madurai, Tamil Nadu, India.

---

## 1. What's New in This Enhanced Release

### Redesigned & Realigned Navigation Bar
- **Perfect Horizontal Desktop Alignment:** Clean, uncrowded single horizontal row on all desktop and laptop resolutions (1024px–1920px+). Zero awkward wrapping or overlapping elements.
- **Executive Brand Lockup:** Integrates the official corporate logo (`ist-logo.png`), vertical separator, typography, and division pill tag (`SKILLS ACADEMY • Madurai Centre`).
- **Prominent "Enquire Now" CTA:** High-conversion coral gradient action button with micro-animated arrow hover transition.
- **Scroll Progress Indicator:** A dynamic 3px gradient progress bar seamlessly tracking scroll depth across the top of the interface.
- **Mobile/Tablet Drawer:** Touch-friendly collapsible navigation with direct contact shortcuts.

### Visually Unique Hero Section
- **Editorial Eyebrow Badge:** Animated pulsing indicator highlighting *"Admissions Open • Practical Technical Education"*.
- **Interactive Code & Architecture Switcher:** A glassmorphic terminal component embedded in the hero screen allowing users to toggle between live stacks (*Full Stack API*, *Python Core*, *Modern Frontend*) with authentic syntax.
- **Dual-Action CTAs & Trust Badges:** Instant access to 8+ course tracks, enquiry submission, and practical training metrics.

### Course Catalogue with Instant Search & Filtering
- **Live Real-Time Search Bar:** Instantly searches across course titles, descriptions, and skill tags as you type.
- **Category Filter Tabs:** Filter between *All Courses*, *Full Stack & Web*, *Programming Languages*, and *Core Foundations*.
- **Live Results Counter & Empty State:** Shows matching course counts with a single-click reset button.
- **Dynamic Curriculum Modal:** Displays course overviews, core competencies, detailed syllabus modules, and practical capstone project specs.

### Animated Step-by-Step Learning Journey
- **Scroll-Triggered Progress Line:** Connecting track dynamically fills with an animated gradient line as the user scrolls into view.
- **Interactive Milestone Badges:** Step numbers (01 to 04) highlight with glowing accent states.

### Elevated Contact & Enquiry Section (Highest Priority)
- **Interactive Learning Mode Radio Tiles:** Custom visual selection cards for *In-Person Lab (Madurai)*, *Online Guided*, and *Hybrid Track*.
- **Indian Mobile Number Digit Counter:** Live indicator `(0/10 digits)` with strict regex validation (`/^[6-9]\d{9}$/`).
- **Real-Time Inline Feedback:** Immediate validation on blur and input for all mandatory fields.
- **Double-Submission Protection & Loading State:** Button disables with animated spinner during simulated processing.
- **Structured Confirmation Review Receipt:** Renders verified applicant parameters with clear prototype indicator and a reset button to test subsequent submissions.

## 4. How to Run & Preview Locally

Because this project uses standard HTML5, CSS3, and Vanilla JavaScript, it requires **no build tools, no npm install, and no local compilation**.

### Option A: Direct Browser Launch (Simplest)
1. Open the project folder.
2. Double-click `index.html` to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option B: Local HTTP Server
Using Python (if installed):
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`

Using Node.js:
```bash
npx serve .
```
